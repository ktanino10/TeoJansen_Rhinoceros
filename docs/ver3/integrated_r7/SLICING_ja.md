# r7 代表5点の実ツールパス点検

**5点を実スライスし、層を確認しました。製作認定ではありません。** 歯数と歯元の連続、モデル側の穴は確認できましたが、2つの歯車では軸穴を横断する支持の初層0.2mmを除去する必要があります。実物での支持除去・歯の仕上げ・はめあい・強度は未確認です。

この記録はr7-15/slice1の代表5点です。対象STLはレビュー済み `f50978e55384d1b03417ed7115395e6e2c010e85` とバイト一致し、その5点は後続の[床干渉是正](FLOOR_CORRECTION_ja.md)でも保持しています。後続版の全CAD・質量・BOMが不変という意味ではありません。全機や全140件のSTLをスライスした結果ではなく、変更したC・足部もこの5点の実スライスに含めません。購入・プリンター接続・送信・印刷・ドライヤー運転は行っていません。

[凍結した229ファイルの不変確認](frozen_artifact_invariance.json)は旧slice1時点の履歴です。r7-16の形状変更へ流用せず、各版の契約と変更対象を分けています。

## 使用した仮定と来歴

公式 [OrcaSlicer 2.4.2](https://github.com/OrcaSlicer/OrcaSlicer/releases/tag/v2.4.2) のMac Universal版をApple Siliconで使用。公開SHA256一致、署名検証、macOSのNotarized Developer ID受理を確認し、ユーザー設定とは別の領域で実行しました。安全警告の回避や認証情報の入力はしていません。

公式P1S 0.4mm、0.16mm Optimal、Generic PETGを**検査上の仮定**として使用しました。実機がP1S／0.4mm／この材料であるとの確認ではありません。255°C、Textured PEI 70°C、初層0.2mm、以降モデル層0.16mm、Arachne、4周設定、100% rectilinear、上下5層、外周brim 5mm。歯車2点はnormal(auto)支持、支持上面gap 0.2mm／XY gap 0.35mmです。支持の独立層があるため、総層数とモデル層数は異なります。

CLIはleafプリセットの`inherits`を自動展開しないため、公式親設定を展開し、**CLIが書き出した実設定**で機種・256mm床・PETG・密度・層高・支持等を照合しました。名前だけPETGで中身がPLAの既定値になる入力は採用していません。

この公式設定のノズルoffsetは`[0,2]mm`です。[Orcaの座標変換](https://github.com/OrcaSlicer/OrcaSlicer/blob/v2.4.2/src/libslic3r/GCode.cpp#L8123-L8134)に従ってG-code座標からモデル床座標へ戻し、3MF内の初層bboxとも0.022mm未満の差で照合しました。自動配置によるZ軸回転は実3MFから記録し、ゼロ回転とは記載していません。

CLIではOpenGL 3.4コンテキストを作れず、3MF内サムネイルの生成をスキップする警告がありました。省略可能な`filament_retract_lift_above/below/enforce`項目が変換元にない旨も記録されています。実G-code・設定出力は生成され、上記の主要な有効設定を照合しています。公開画像はG-codeから別に描いた層図であり、生成できなかったサムネイルを代替の完成画像で埋めてはいません。

## 支持・除去の残件

入力ピニオンの歯面は書き出し姿勢で床から10mm上にあり、支持なしでは初層にOverhang wallが生じました。この姿勢では支持を追加します。同様のA/C入力部品の`supportsMayBeRequired`と生成元を修正しました。Bは歯面が床から始まる別配置なので、この変更を機械的に横展開していません。このスライス記録の作成時点では全案の実STLを変更していません。

歯車の支持は下側の歯面・スポーク・肩へ接触します。歯間側面とはXY gapを取りますが、除去時の下縁欠け・バリは噛合いに影響し得ます。外周、スポーク間、開放された底面から支持にアクセスできる配置は画像上で確認しましたが、**実際の除去力や仕上げ後の歯形は確認していません**。

両歯車とも、支持が軸穴を横断するのは床側の最初の0.2mm層だけです。支持初層拡張を2→0mmにした比較でもこの薄膜は残り、解消したとは扱っていません。最終設定は2mmを保持しました。深い穴内部に支持柱が残る配置ではありませんが、開放底面の支持を除去してから穴・ジャーナルを確認する必要があります。現物作業をしていないため、製作リリースはfalseのままです。
