# r7-16-floor1：全物体と床の不整合に対する限定是正

**旧r7-15/slice1には床干渉がありました。支持足の計算PASSは、全物体と床の非干渉を意味していませんでした。** PR10と旧資料の履歴は改変せず、[失敗対照](review/floor_conflict_baseline.json)を保存しています。これは作者による是正・検査で、新しい独立レビューや実歩行試験ではありません。

正規の床はZ=0、CADの本体基準Zは70mmです。保存された本体高さ・勾配への一次写像を、元メッシュの倍精度座標へ直接適用して再現しました。描画上の直交化や未解決ロッカー角が原因ではありません。

|旧版の対象|確認した床下Z|
|---|---:|
|C下側／左PET、0／120／240度|−5.201387／−5.519445／−4.388603mm|
|Cの156歯出力輪、保存110度の実メッシュ|−1.249765mm|
|B左PET、120度|−0.011338mm|

旧Aもガードの全周余裕が十分ではなく、誤差・ばね・案内摩擦の既存ケースへ広げると、3mm付加幅を残した最初の輪郭案は不合格でした。3点だけを切り欠いたり、床を下げたり、部品を消したりして対処していません。

## 実体を変更した範囲

**Cは2段を12×13から13×12へ再配分**しました。総156:1、m1、25度、12歯ピニオンを保ち、大きな156歯を高い中間軸へ移し、床に近い最終輪を144歯にしました。中間軸速度は−13から−12回転／クランク回転へ変わります。軸位置・位相・フレーム・ガード・質量・重心・歯車反力・損失・荷重・接地フレームを、新しいCADに対応させています。旧Cの数値をそのまま貼り替えていません。

**全案の左右PETは、最大径に合わせた全幅の矩形下縁を廃止**しました。保持点と上側連結部を残し、歯車回転包絡を覆う輪郭です。上側の付加幅3mmに対し、床に近い最終輪の下側輪郭は0.65mmの被覆付加幅を持ちます。切り出し等の0.3mmプロフィール余裕を差し引いても0.35mmを残す設計で、歯先そのものを露出させるための検査除外ではありません。安全ガードの規格認証や実たわみの保証はしていません。

**ロッカーピンの外側突出も、全ケースで検出して実体を是正**しました。足位置・接地パッドの半径／面積・ばね定数・6mm行程は変更していません。

- スライダーの外側座面を1mm内側へ段付けし、8mm平滑金属スリーブの端面で鋼座金を受けます。ねじ山を摺動面にはしません。
- 既存M2×16を頭下面から12.5±0.1mmに切断・端面処理する部材計画です。2個の通常M2ジャムナットを保持し、許容短寸法でも外側ナットから0.6mm以上の完全ねじ部を残します。実加工は未実施です。
- ロッカーの非接地ボス半径を5→4.3mm、軸方向幅を3.8→4.4mmへ変更しました。2つの接地パッドは元の形状・位置のままです。
- 内側の鋼座金はM4小形の内径4.5／外径8／厚0.5mmに変更。ロッカーと両座金の合計5.4mm、フォーク内側6mmに対する自由すきま0.6mmは維持します。

追加する国内座金は[鉄・小形M4、100個税込330円](https://www.nejinejikun.com/products/detail/94368)の1lotで、1台に12枚使用します。元のM4座金は他の保持部で使用するため、重複計上や不当なlot削減はしていません。[メーカー寸法表](https://www.nejinejikun.com/html/upload/save_image/kikaku_data/a4010100000000_d.gif)の内径4.5mmと公差を確認していますが、現物寸法・偏り・摩耗は未認定です。

## 同じ条件による床チェック

各案で**名目0.5度刻み720姿勢＋既存162ケースの2度刻み180姿勢＝29,880姿勢**を確認します。162ケースは従来の27組の寸法・位相・床・ばね誤差に、3つの案内摩擦モードと2符号の入力偶力を組み合わせたものです。ケースや不利条件を間引いていません。

実nativeの面・稜線を含む包絡を用います。平面境界、完全円を含む外接多角形、円筒、必要に応じた面の包含箱を使用し、名目メッシュの三角形頂点だけを曲面の厳密な下限とは扱いません。歯車はnative面／稜線から半径上限を確認した回転円筒です。

**全instanceを追跡**します。意図して接地する2個のローリングパッドの体積だけをロッカーから区分し、残りのボス・梁・全金具は検査対象です。残るロッカー芯部は、独立角をゼロと仮定せず、物理ストップの±5度全域を包含します。部品・回転instanceを落とす入力はエラーにします。

床の既存高さ上限+0.3mmに対し、保持した名目リンク形状と切出しPETには別途0.3mmの材形状余裕を取ります。寸法誤差で既に動かした関節／足位置へ、同じリンク長誤差を鋼ボルトの長さとして二重加算しません。購入品の未提示公差、任意の凸凹、衝撃、全連続クランク角の証明ではありません。
