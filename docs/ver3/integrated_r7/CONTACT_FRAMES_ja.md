# 既存接地モデルの描画用フレーム

これは**既存の収束済み準静的接地結果の保存**であり、新しい歩行モデルや実験動画ではありません。CAD・荷重・風・摩擦・ばね・収束条件は変更していません。`analyze_integrated_walkers.py`が既に計算していた`ContactGait.evaluate()`の結果を、捨てずに薄く書き出します。

[A](A/contact_frames.json)／[B](B/contact_frames.json)／[C](C/contact_frames.json)は同じschemaです。0.5度刻み720点の正規解から5度刻み72点を取り、周期の終点を明示した計73フレームを保存します。終点360度の接地状態は周期0度の収束解、前進・横移動・ヨーの累積量は元の720点を積算した値です。ゼロや前値で未収束状態を補完したものではありません。

## 含むもの

- 版、ソースcommit/hash、入力・assemblyのhash、座標系、単位、脚の順序。
- クランク位相、符号付き入力軸角、本体高さと2つの勾配、元の密な速度列を積算した前進／横移動／ヨー成分。
- 各足の圧縮、案内方向、モデル接地点、法線力、荷重判定、滑り速度。
- 収束残差と元の全位相の集計量、**仮の入力120RPM**に対する表示時刻。

前進は既存ソルバーの速度を同じ矩形則で積算した値で、任意の直進速度を追加していません。符号付き前進と、旧集計が使う移動距離の絶対値は区別します。120RPMは到達・予測速度ではありません。

入力軸は1表示区間で複数回転します。`inputDegUnwrapped`を360度で丸めて補間すると、見かけ上停止する等のエイリアシングを起こします。符号付き非折返し角と表示時刻を保持してください。

本体姿勢は元の`body_z_slopex_slopey`そのものです。小角近似の座標写像を保存し、厳密な剛体world行列や新しいSE(2)運動積分に置き換えていません。ネイティブCADのZと本体基準からの相対Zを混同しないよう、`cadReferenceBodyOriginZMm`と写像を併記しています。

## 含まないもの

**独立した各足ロッカー角はnullです。** 正規モデルは足ごとの代表接地点と受動ロッカーの近似で、ロッカー角を独立に解いていません。最大必要角の感度・包絡と、時系列の確定角は別物です。描画の都合でゼロ角、前値、任意姿勢に置き換えてはいけません。

実入力速度、衝撃、動力学、ばね線材の時々刻々の変形、実摩擦・床・風の実測を含みません。欠けた状態を要求する完全な歩行レンダーは、この出力だけでは確定できません。比較CG・schema2の組立表示とは別に扱い、表示側は不足成分と小角・準静的近似を明示する必要があります。

## 検査と再現

集計との照合は[保存時の整合記録](contact_frames_validation.json)を参照します。従来の`work_budget.json`と`work_profile.csv`は上書きしません。再現時には`--output-dir`で別の解析出力先を指定し、`--motion-output`と`--source-commit`でフレームだけを保存します。全CAD生成・全公差／干渉ケースの再実行は不要です。

フレーム間の補間は表示上の操作であり、接地切替を追加検証したことにはなりません。`manufacturingRelease=false`、実始動・30cm歩行はUNKNOWNを保持します。
