# C転位歯車対の追加2点スライス

**Cの新しい相手2部品を実スライスし、歯数・歯元のつながり・穴・支持を確認しました。造形／噛合いの現物認定ではありません。** 入力は `f72b2cf64813978f0d31d1a1eaeb4d968948caf5` のC用STLに固定しています。[従来のA／共通5点](../SLICING_ja.md)は別の不変な記録で、混在させません。

新しい最初の一対はm0.9・20度、12／156歯、転位+0.35／−0.35です。複合部品の次段12歯はm1・25度です。旧CやAの入力歯車とは混用しないでください。

OrcaSlicer2.4.2、仮定P1S0.4mm／Generic PETG／モデル層0.16mm／Arachne4周設定／100%／normal支持を使用。実機・実材料の一致は未確認です。公式設定の継承と有効値、ノズルoffset、3MF配置とG-codeの座標を照合しました。

|対象|モデル層／支持込み総層|材料推定|総時間推定|実層の確認|
|---|---:|---:|---:|---|
|C入力ピニオン|219／254|1.69g|24分52秒|12歯保持、歯元へ連続、D穴を全モデル層で維持|
|C複合1|275／342|46.35g|2時間43分15秒|156歯と次段12歯保持、スポーク・歯元へ連続、六角穴を全モデル層で維持|

支持・立上げ等を含む、この個別条件でのソフトウェア推定です。全機の材料費・実造形時間へそのまま換算していません。

**156歯輪の最初の支持面層Z20.2mmでは、原STL輪郭から最大約0.052mmの歯先後退があります。** 内部層Z21mmは0.001mm未満でした。これを旧A試料の「0.04mm未満」と同じ結果に書き換えていません。全歯数は残っていますが、最初の面の支持除去・歯下縁の仕上げと実噛合いは要確認です。

両部品の軸穴には、底面の0.2mm支持層だけ薄膜が残ります。深い穴内へ支持柱が続く結果ではありませんが、現物での除去・穴径・はめあいは未確認です。生G-codeと設定入り3MFは私有領域に保持し、公開していません。
