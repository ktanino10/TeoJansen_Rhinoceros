# Ver.3 — 組立・装着経路・ベンチ確認

**図面を見て組める比較試作の手順です。現物での組立確認・印刷・風力試験は未実施です。** 不明な購入品の寸法や材料、締付仕様を、CAD の簡略表示から決めないでください。

部品番号・数量・切断長さは [BOM A](BOM_A.csv) / [B](BOM_B.csv) / [C](BOM_C.csv) が正本です。`printed` の部品だけが各 `STL/Ver.3/A|B|C` の印刷対象。`purchased` と `cut_to_length` は購入／加工品です。Q から始まる二種類はフィット試験片で、組立数量 0 としています。

座標は **X＝軸方向、Y＝脚の進行平面、Z＝高さ**。左端は −X、右端は +X です。機体の見た目の前後と混同しないでください。左右鏡映した脚三角形には `_R` を付けています。

## 工具と事前条件

ノギス、0.05/0.1 mm 程度のシム・すきまゲージ、まっすぐな芯出し棒、2.5 mm と 3 mm 六角棒レンチ、5.5/7 mm の小型スパナを用意します。M4 皿頭・M4 ボタン頭は 2.5 mm、M4 通常キャップ頭と指定ハブの締結は 3 mm が基準です。実購入ねじで照合してください。

REX 軸は BOM の長さへ切断・端面仕上げし、両端に M4 の軸方向タップを加工する仕様です。適切な治具と加工経験がない場合は加工済み品／加工サービスを確認してください。カタログにその切断長さが在庫しているという意味ではありません。

印刷は **100%、mm**。過去の 150% 設定を追加しません。歯車・フレーム・フォーク・脚は平らな面をベッドへ、カップは端面をベッドへ。STL は最低 Z を 0 にした向きです。軸受座・ハブ締結部・薄いリンクなどの局所充填、寸法補正、カップのブリムは試験片で決めます。未確認のスライサー設定から強度や質量を保証しません。

A の最大フレームは約 **254.4 × 256 mm**で、256 mm 角の造形面に対するブリムや端部余白を含みません。使用する機械の実際の使用可能範囲・禁止領域をスライサーで先に確認してください。入らない場合に倍率だけ縮小すると購入部品が合わなくなるため、より大きい使用可能面か、別途の分割設計が必要です。ここでは造形できたとは主張しません。

## 番号付き組立順

1. **二つの試験片を先に確認する。** `Q_BEARING_FIT` の 21.9/22.1/22.3 mm ポケット、`Q_JOINT_FIT` の穴を使い、実購入の軸受・軸・ブッシュに合わせます。図面の 22.2 mm 座は FDM 補正を含む出発点で、実物がその径なら適切という保証ではありません。過大なガタや圧入で割れる組合せを本体へ使わないでください。

2. **軸・スリーブ・スペーサを仕分ける。** 中間 REX 軸、両端軸、風車軸、6 mm 固定軸、M4 タイロッドを BOM の部品 ID で分けます。切断チューブの長さは似ていても役割が異なります。端面を平行に仕上げ、バリで内輪や樹脂を押さないようにします。M4 軸端穴はボルトが底付きせず必要なねじかかりを得るか確認します。

3. **フレームと押さえのナットを先に入れる。** `P_FRAME_LEFT/RIGHT/CORE/FRONT_LEFT/FRONT_RIGHT` の M3 六角座へ、背面が開いている間にナットを入れます。軸受を入れる力は外輪に加えます。`P_BEARING_RETAINER` は外輪だけを保持し、中央 20.2 mm 開口から軸・内輪スペーサが自由に通ることを確認します。キャップを締めて内輪やシールドまで挟まないでください。

4. **A だけは入力軸受キャリッジを準備する。** 三つの `P_INPUT_CARRIAGE_*` へ M3 の押さえ用ナットを裏から入れ、軸受と押さえを取り付けます。主フレーム／左前キャリアの入力軸部は 28 mm の逃げ穴で、軸受座そのものではありません。キャリッジを四本の M4 皿頭ねじで長穴へ仮止めし、まだ張力調整を固定しません。皿頭は面一、裏側は座金と緩み止めナットです。

5. **風車を独立したサブアセンブリとして組む。** A/C は `P_ROTOR_CORE`、一体の `P_ROTOR_YOKE`、二つのカップを使います。別々の細い腕を重ねる構造ではありません。フォーク根元の二本の M4、カップ端の M3 を、開口しているナット座から締結します。反対端は `_R` の穴配置です。B は小径の端板へ直接カップを止めます。ハブは四本の M4 で端板へ結合します。接着剤をトルク伝達に使いません。

6. **六脚を非鏡映／鏡映で分けて仮組みする。** AB、AC、PC、DE 棒と PBD、CEF 三角形を正しい組合せにします。B/C/D/E の関節は、3 mm の樹脂を 3.2 mm の金属スリーブがわずかに越える構成です。ねじを締めても金属スリーブ・スペーサ側で止まり、樹脂の関節を固定しないことを手で確かめます。ねじ山を直接の摺動面にしません。P の 6 mm 固定軸用スリーブとは取り違えないでください。

7. **三つの共有クランクを組む。** 金属ハブを二枚の `P_CRANK_CHEEK` へ皿頭 M4 で固定します。頭は棒が通る側へ突出させません。ハブの四角い穴パターンだけでなく、**購入ハブの REX 対辺の向き**も合わせます。正規モデルの軸角は角部基準 15°、向かい合う反転ハブはさらに 90°インデックスした配置です。90°回しても四つの取付穴位置は変わりません。軸を無理にねじ込んだり、クランク位相をずらして合わせたりしないでください。REX 軸を入れ、M4 ボタン頭と 12 mm 外径の薄い軸端止め座金を凹部へ収めます。二枚の頬板の間には、下表の 20 mm 積層を置き、M4×45 のピン・座金・緩み止めナットで両持ちにします。軸端止めの操作は、脚が主軸中心を遮らない図面の基準姿勢で行います。

8. **主機構を −X から順に閉じる。** 主左フレーム → クランク・対向二脚 → 次の軸受フレーム → 次のクランク、の順に仮組みします。6 mm 固定軸と二本の M4 タイロッドには、対応する脚スリーブ・スペーサ・アルミチューブを順に通します。**32 mm ハブを 8 mm 軸受穴へ通そうとしない**でください。隣のフレームを閉じる前に、その区間のハブと軸を入れます。外側のクランクは 0°、中央は 180°、外側は 0°。二本の中間 REX 軸とすべての頬板の位相を確認します。

9. **風車軸と連絡軸を入れて最後の主フレームを閉じる。** 風車サブアセンブリを支持フレームの間へ置き、軸の自由端へ最後のフレームを通します。連絡軸 M1、B の M2 は脚・風車の可動域から離れた通り道です。芯出し棒で同軸度を確認し、段階的にタイロッドを締めます。固定軸のスペーサを突っ張らせたり、複数軸受の外輪を軸方向に締め付けたりしません。

10. **靴と交換可能な足裏を取り付ける。** F の金属スリーブを介して靴を M3 で取り付け、靴のピッチ関節を締め殺さないようにします。足裏は二本のタイで保持し、足裏の浅い溝へタイを収めて下面を極端に突き出させません。B は CEF 三角形の軸方向位置が A/C と異なるので、他案のスペーサを流用しません。靴の幅で重心問題を隠すのではなく、段の左右配置とレイヤー位置を合わせることが重要です。

11. **左右の段を、主フレーム側から外側へ取り付ける。** 四本のケース用 M4 ロッド、指定のチューブ、ガード背板を順に通します。ガードの非取付部分にはロッド／チューブの実際の通過穴があります。ハブと歯車の四本の取付ねじは、ケースの外で先に締結し、手順7の対辺基準と反転ハブのインデックスを守ります。後から歯車を通して裏側のねじへ工具を届かせる構成ではありません。B の右側では **S1 とその窓を先に完成させてから S3** を取り付けます。左 S2 は連絡軸へ取り付けます。最後の外側窓も前側軸受キャリアより先に締結します。前側キャリアは、手回しや A の芯出しのために仮組みできますが、窓ねじへの工具経路を塞いだまま窓を締めようとしないでください。

12. **A のベルトを装着・調整する。** 24T 側は、メーカー図の通し穴・座ぐりを使う角度でハブへ取り付けます。二つのねじ穴同士へ無理に一本のボルトを通して締め合わせないでください。48T 側とベルト溝の軸方向位置を揃え、520×9 mm ベルトを掛けます。前側キャリアを開けた状態なら、ベルトをフランジ越しに無理に伸ばす必要はありません。前側キャリアを仮組みし、三つの入力キャリッジを同一の芯出し棒で揃えて張力を調整します。長穴の設定位置を記録し、**前側キャリアはキャリッジ・軸受ごとのユニットとして一度外して窓を締結**してから戻します。窓には、軸穴とは別に**キャリッジ固定ねじ用の四つの8.4 mm逃げ穴（入力軸周囲の36 mm正方形）**があります。これは先端が窓を貫通する四本の M4×30 と ±1.5 mm の調整範囲を逃がすための孔で、省略できません。長穴の設定を不用意に緩めず、戻した後も芯出しと手回しを再確認します。10 N/スパンは計算用仮定で、実験で確認した張力ではありません。M1 と二次歯車の中心は固定したままです。A S1 の窓は **軸穴13 mm・M3×40**、平歯車段の窓は **軸穴10 mm・M3×35** で、BOM と型紙もこの段別仕様に従います。

13. **位置決め・抜け止めを調整してケースを閉じる。** 中間軸と風車軸は指定された位置決め軸受の内輪だけをスペーサとカラーで扱います。主クランク側はハブ・カラー・端部止めの組合せです。名目 0.2 mm の軸方向すきまを実物で測り、逃がす軸受を締め上げません。ハブの金属締付ねじはメーカー指定に従います。入力とクランクの回転方向・比率を仮組みで確認した後、**窓ねじを締めてから前側キャリアを戻し、最後に軸端止めとケース固定を完成**します。主フレーム内の軸受とハブを保持し、キャリアを外している間は風車・連絡軸・クランクを手や適切な受台で支え、駆動しません。ガードは飛散防止の概念部品で、認証された指保護・衝撃保護ではありません。

14. **分解は前側キャリアを先に外す。** 風・駆動入力を止め、本体と回転体を受台などで支えます。外側から操作できる軸端止めとケース用ロッドの外側固定を解放し、**前側キャリアを軸受・押さえ付きユニットとして外へ抜いてから、外側窓 → ハブ締結 → 外側段 → 内側窓／段**と進めます。主フレームの軸受と位置決め部は残し、長い軸やローターを自由落下させないでください。A の入力キャリッジは設定した長穴位置を変えずキャリアと一緒に外し、再取付後に芯を確認します。B では S3 の窓・歯車・ハブ・ガード背板と対応スペーサを取り除いてから S1 の窓を操作します。ハブやプーリーを軸受内径に通すのではありません。ローター全体を取り出す場合は主フレーム側の組立順まで戻します。分解動画の同時移動は説明用であり、この順序や回転体の支持を省略できるという意味ではありません。

## 装着経路と工具空間の読み方

実形状の断面は [drawings](drawings) にあります。軸受・ハブ・軸端止めの断面を、完成レンダリングだけでなく確認してください。

[装着経路の CAD 確認 A](assembly_access_A.json) / [B](assembly_access_B.json) / [C](assembly_access_C.json) は、表に明示した分解状態でのナット取り出しと歯車・ハブ／ベルト付きプーリーの軸方向経路を記録します。完成した前側軸受を通り抜けられるという確認ではありません。

| 部分 | 必要な順序・空間 |
|---|---|
| 歯車の M4 フランジねじ | ケース外で歯車＋ハブを先に結合。面の裏へ後からアクセスする必要をなくす |
| ハブの締付 | 前側キャリア、外側窓を順に外して回転体を支え、軸を必要な角度へ回して3 mm レンチを入れる |
| 軸端 M4 ボタン頭 | 軸端側からアクセス。凹部が棒の掃引を侵していないこと |
| キャリッジ M4 皿頭 | 正規の長穴を使い、三つを同じ軸線へ。締付後に芯出し棒を抜けること |
| ガード窓ナット | 背面が開いた段階で六角座へ入れる。閉じた空洞へナットを押し込む構造ではない |
| ガード窓ねじ | 一部が前側キャリアに隠れる。キャリアを先に外し、BではS3窓／段を外してからS1窓へ。特殊な極短・大角度工具を暗黙に仮定しない |
| カップ／フォークのナット | カップの凹側から入れる。曲面壁とナット・工具の軸方向経路が重ならないこと |
| 連絡軸・ハブ | 連絡軸を先に通し、ハブを段階的に取り付けてから前側キャリアを閉じる |

## ベンチ確認票 — すべて未実施

この欄は実測用です。計算や動画を、下の試験を実施した証拠にしません。

| 未実施項目 | 記録する内容／中止条件 |
|---|---|
| フィット試験 | 軸受外輪座、軸・ブッシュ、穴径。割れ、過大ガタ、強い圧入があれば本体へ進まない |
| 目印付きトルク伝達 | 軸・ハブ・歯車に連続する目印を付け、低い負荷から確認。接着で滑りを隠さない |
| 軸方向すきま | 冷間で約 0.1–0.3 mm を出発点に実測。メーカー条件・実物に応じて再設定。締付で急に重くなるなら停止 |
| 保持 | 軸端止め、カラー、四本の歯車ボルト、ケース。低い手荷重で抜け・緩みがないか。破壊まで試さない |
| 各段の空転 | 脚を接続する前後、ベルト張力変更前後で始動抵抗を分けて記録 |
| 全周の手回し | 全脚を最低二周期。棒、固定軸、チューブ、ケース、靴の干渉・引掛かり・大きなガタがあれば停止 |
| 角度別クランクトルク | 小さな力計と既知の腕長で複数角度を測る。必要なら `力 × 腕長` を単位換算して比較 |
| 質量・重心 | スライサー値だけでなく実測値。部品質量差やケーブル／追加部品を含める |
| 机上歩行 | 接地材料点の滑り、片脚荷重、靴の受動回転、転倒、フレームの曲がり。動画との違いを記録 |
| 風車単体 | 風速・方位・ローター角を記録した静的トルク。悪い角度のゼロ／逆トルクも記録 |

風での自由歩行はこれらの確認と保持・転倒リスクの評価後です。3D プリントの破損や部品飛散があり得るため、未検証の大風車を人の近くで無監督運転しないでください。ここでは購入、印刷、機器操作、風力試験を行っていません。
