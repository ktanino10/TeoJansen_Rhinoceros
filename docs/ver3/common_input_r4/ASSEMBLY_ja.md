# 共通入力カートリッジの組立・脱着

**`v3-common-input-r4-01`。実CADで検査した部分組立順です。印刷・実組立・機器操作は未実施です。** これはV2への無加工差替え部品ではなく、新しい共通入力部です。ローター・脚・歯車列や、紐・硬貨の荷重治具は含みません。

座標はX＝軸、Y＝左右、Z＝上。左から右へXが増えます。[BOM](BOM.csv) と [正規インスタンス・手順集合](assembly.json) を正本にしてください。ネイティブのラベルは以下の部品名と一致します。

## 準備

印刷はmm、100%。キャリアはレール底面をベッド側、押さえ・フランジ・試験片は平面をベッド側にしたSTLです。キャリアの軸受穴は横向きで、サポート／ブリッジ／清掃方法は未スライスです。穴の清掃とフィット確認なしに本体へ軸受を押し込みません。従来の150%設定を適用しません。

工具は外部M4用の3mm六角、ナット用7mm、購入ハブのクランプ用2.5mm六角、カラーのクランプ用3mm六角が出発点です。実購入のねじで確認します。寸法・すきまを確認する道具は製作時に必要ですが、現在ユーザーが持っていると仮定せず、購入や測定を代行していません。メーカーの公表数値がない締付トルクをここで創作しません。

## 組立順

1. **試験片とキャリアを確認。** `Q_BEARING_FIT` は数量0の試験片で本体に付けません。角に2×3mmの欠けがある端から14.0／14.15／14.3／14.45mmの順で座を実部品と比較し、本体の14.2mm名目穴が適切かを確認します。きつい穴をねじ締結の力で圧入したり、軸受内輪へ力を掛けて外輪を押し込んだりしません。本体取付穴は4つありますが、相手材と取付ねじの指定・固定を別途確認します。

2. **`BEARING_LOC`を左から入れ、`CAP_LOC`を付ける。** フランジを左向きとして、軸受はX=14～19mm、フランジは14～15mmです。キャップはX=10.7～13.7mm。M4×20を2本、座金を頭側／ナット側各1枚、緩み止めナット各1個で取り付けます。キャップをキャリアの座へ寄せても、外輪には名目0.30mmの空間が残ります。軸やカラーを入れる前ならナットへ一直線に工具が届きます。

3. **`BEARING_FLOAT`を右から入れ、`CAP_FLOAT`を付ける。** 軸受は名目X=94～99mm、フランジを右向きにします。フランジはX=97～100mmの長い溝の中を動きます。キャップは100～103mm。左と同じM4×20×2本、頭／ナット側座金、緩み止めナットを使います。外輪の名目±1mm移動を残し、カラーを右へ追加して軸方向に締めません。

4. **`D_HUB`＋`TEST_FLANGE`をキャリアの外で先組み。** 16mm正方形の4穴を合わせ、14mmパイロットを14.3mm・深2.15mmポケットへ向けます。M4×12と1mm座金各4個。名目ねじかかりは7mm、ハブ裏面まで1mmです。これらの外部4本と、ハブ自身の2本のクランプねじを取り違えません。先組みユニットを上から支点の間へ置きます。表示の完成位置は、軸にすでに固定したことを意味しません。

5. **左固定側のスペーサーとカラーを配置。** `SPACER_OUT`はX=10～14mm、`SPACER_IN`は19～23mm。カラーのボスを各スペーサーへ向けます。外側カラーのボス面9.9mm、内側カラー23.1mmが名目位置で、両側0.1mmずつ、計0.2mmの遊びを設けます。2つのカラーを左右の軸受に分配するのではありません。まだ軸がない部品を支持し、落下させません。

6. **クランプを解放し、`SHAFT`を左から入れる。** 外側カラー、外側スペーサー、左軸受、内側スペーサー／カラー、ハブの順に通し、右軸受まで通します。メーカー指定の6mm D軸と金属Dハブの組合せです。D平面の方向を合わせ、きつい場合に無理に押したり、軸を削ったり、ハブをCADで拡大したりしません。参照モデルの微小交差と現物の適合は[説明](README_ja.md)の区別に従います。

7. **位置と自由すきまを確認して固定。** ハブ本体はX=35～43mm、試験フランジは43～47mm。内側カラーとハブの間にも空間を残します。カラーねじは軸へ固定するためのもので、軸受へ押し付けて予圧を加える調整ではありません。外輪の遊び・内輪積層の全0.10～0.30mmすきま・右外輪の移動・締付後の回り方を確認します。部品がこすれる、押さえが沈む、締付けで重くなる、強い芯ずれがある場合は進めません。特定の締付トルクや低い始動抵抗は未確認です。

8. **動力を入れない確認段階として完了。** この資料からドライヤー、モーター、紐荷重の操作へ進む指示はありません。机上固定、購入部の締付仕様、現物フィット、必要な防護を別途確認します。無負荷で軽く見えることを、供給トルク・全角自己始動・30cm歩行の合格とはしません。

## 脱着の順序

![実CADからの脱着説明配置](removal_sequence.svg)

動力を使っていない・完全停止した支持状態で、ハブとカラーのクランプを解放します。**軸を左へ抜いてから**、ハブ／試験フランジの一体ユニットを上へ取り出します。内側カラー・スペーサーも軸が抜けた後に取り出します。32mmハブを6mm軸受穴へ通したり、軸を残したまま上へ引き抜いたりしません。

図では説明のため軸を124mm左、先組みフランジを50mm上、カラー類を横へ離してあります。一斉にその方向へ動かす手順ではありません。軸の左抜き、フランジの上抜きの各経路は `assembly_access.json` の別項目です。D界面の解除状態／実はめあいはメーカー指定と現物で確認します。

軸受やキャップを外す場合は、先にこれら回転部を取り除き、キャップのねじとナットへ工具を戻します。左軸受は左、右軸受は右へ抜く経路です。ハブがキャリア内にあるままナットドライバーを長く差し込めると仮定しません。

## 工具経路と公差の読み方

`assembly_access.json` には、7mmナットドライバーを外径12mm・長さ28mm、キー軸を直径4mm・長さ26／28mmの包絡で確認した結果があります。クランプは回転体一式を同じ停止角へ合わせたときに、上半空間からアクセスできる角度を記録しています。作業中に自動で回転させる意味ではありません。手持ち工具の外形、手指、全角度での操作性を保証しません。

左右のキャップ座の押し込み・締結変形は実測していません。寸法受入計算はキャップの圧縮／沈みを0.05mmまでと置いており、それを超えた場合は前提外です。**樹脂を押し潰して寸法を合わせる、ガタを締付けで消すことを前提にしません。** 金属の外輪・内輪の当たり面、左右の公差、熱・たわみの余白は別々に確認します。

このカートリッジで形状・個数・経路が確定しても、全機の新しい三案、実ローターの捕風効率、実部品の摩擦は次の工程として残ります。
