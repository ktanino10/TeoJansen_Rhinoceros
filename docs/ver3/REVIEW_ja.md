## 初回独立レビューで確認した範囲

- FCStd 全フィーチャ、正規部品 ID・配置・体積・仕様、STEP の有効性とソリッド数を独立に読込み。初回の native/STEP ソリッド数は A827 / B844 / C791 で一致。
- 全印刷 STL の閉じた単一ソリッド、体積、外接寸法。最大寸法が **256 mmちょうど**の部品もあり、ブリム・実際のプリンター端部余裕を保証しないことを確認。
- **15°刻み24姿勢**で、印刷部品と他の実 B-rep 部品の干渉を確認。A3443 / B3676 / C3500 回の実 Boolean 判定で、0.05 mm³を超える交差は検出しなかった。
- 異なる運動をする非印刷部品同士を **10°刻み36姿勢**でも確認。共回りする名目ねじ界面と購入ベルト／プーリーの意図した包絡表現は区別。
- 六つの平歯車対について、native の歯面外周を取り、一かみ合い周期121点で面積交差0を確認。軸の符号付き速度比、購入 HTD5M の長さ・巻付き・幅・取付穴を照合。
- AC と固定ピボットスペーサの最接近角191.5996°を実ソリッドで確認し、0.522766 mmの隙間を確認。開いたクランク区間、スリーブ積層、凹部、軸方向保持、内輪／外輪の接触を確認。
- 宣言された探索を別の出力先へ再実行し、選定 JSON、候補 CSV、構造探索三ファイルが初回版とバイト一致。始動トルク／接触指標も条件付きモデルとして再現。
- Blender を自動スクリプト実行無効の独立プロセスで開き、正規変換に対する配置、スケール・変形の不存在、B のアンラップ回転方向を確認。
- 配布 MP4 を実復号し、各歩行・機構・分解のキーコマを目視。固定地面格子に対する本体の前進、時間倍率、残差失敗、物理未検証の表示を確認。

これらは**標本角での検査**です。連続するすべての角度、あらゆる工具・手指・公差条件での無干渉の厳密証明ではありません。初回検査の数値を、是正後の全検査を再度実施したという意味に読み替えません。是正後は影響箇所を限定して再確認します。

## 製作・性能確認まで残ること

1. **接触目標は全案未達。** 3 mmは設計側の目標で、ユーザーの合格条件を勝手に緩めたものではありません。クリップ開始時の部分接地区間、完全な区間、荷重しきい値なしの全近接足監査を分離して記録します。材料点の水平移動には靴の揺動も含み、実測された地面滑りではありません。
2. **近接足と負荷足は違う。** 近接足3本以上という幾何条件だけでは、実用的な三脚支持を立証しません。仮定重心、受動靴ヒンジ、質量誤差、風による転倒モーメントを含む実機検証が必要です。
3. **B は比較条件下でも入力不足。** 8 m/s・仮定トルク係数0.20でも、名目始動トルクの予算は閉じません。A/C の楽観的なセルが閉じても、不利なローター角や低い係数での自己始動・回転継続の証拠にはなりません。
4. **質量・強度は仮定。** 全ソリッド体積と購入品質量仮定は、実際の印刷質量・重心・積層強度ではありません。AC の Euler 代理比約1.56–1.94も、印刷品の安全率・疲労寿命の保証ではありません。
5. **購入・製作インターフェースの現物確認。** 軸受リング面・すきま・同軸度、金属軸切断と端面タップ、締付仕様、ベルト張力・始動抵抗、ピン／ブッシュ／靴関節の摩擦を確認する必要があります。
