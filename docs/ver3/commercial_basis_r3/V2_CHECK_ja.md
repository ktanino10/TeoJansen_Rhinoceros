# 任意のV2非侵襲チェック — 測定器は購入しない

**共通設計版 `v3-commercial-r3-01` の任意資料です。設計再開の前提ではありません。** 手元にVer.2本体と装着済み風車があることはユーザー確認済みですが、その現物写真、接合部の強度、脱着可否はまだ確認していません。公開済みV3第一カットやR3骨格を、手元V2と同じ形状として扱いません。

## 最初は荷重を掛けない

新しい測定器、硬貨、ひも、追加軸受、巻胴、分解・穴開け・接着し直しは不要です。最初に確認するのは**風車→軸→歯車→脚のどこまで動きが伝わるか**だけです。

1. **電源OFF・完全停止した状態の写真を2枚以内。** 全体と、風車－軸の接合／歯車側軸端です。定規を横に置くなら停止時だけ。無理な分解や手回しはしません。
2. **安全に触れられる場合だけ、接合の両側の対応位置を確認。** 消せる小さな点や既存の形状を目印にし、軸受の摺動面を汚したり、テープ・紙・糸を回転部へぶら下げたりしません。目印を付けられなければ写真の既存特徴を使います。
3. **任意の短い観察動画では無押しの始動と伝達を記録。** 使用する家電の説明書・許容用途に従える条件だけを対象にし、冷風、同じ設定／ノズル、記録した距離・向き、全体と接合が見える構図を保ちます。模型や回転体を手で押したり支えたりしません。目立つブレ、抜け、異音、部品の緩みがあれば継続しません。角度を変えるなら送風を止め完全停止してからで、抵抗を感じる機構を無理に回しません。

「強い風が出る」という申告は定性的な情報として記録し、紙の揺れ・無負荷RPM・カタログ風量からm/sやトルクを算出しません。

| 観察 | 記録すること | まだ言えないこと |
|---|---|---|
| 風車だけ回り、軸の対応目印が追従しない | 接合の相対位置変化、向き、動画 | 原因が軸受焼付き、供給トルクが何mN·mなど |
| 軸は動くが歯車が追従しない | 軸－歯車の相対変位 | 接着を強くすれば全負荷で十分という保証 |
| 歯車まで動き、脚が止まる | 止まる部位・角度、戻り、がた | 脚の必要トルクや地面摩擦の定量値 |
| どこも動かない／時々動く | 初期向き、同じ条件での再現性 | 風不足、静摩擦、死点のどれか一つへの断定 |
| 全体が動く | 進行距離、接地、目印、横ずれ | 全角度自己始動や別のR3風車で同じ性能が出ること |

記録：[CSV](v2_observations.template.csv) / [確認状態JSON](optional_v2_check.json)。未観測は空欄か不明で、停止を0rpmの精密計測やトルク0と書き換えません。

## 硬貨・ひもによる定量試験は、取付可否を確認してから

既知の弱い接着部や羽根へ紐を巻く試験は行いません。写真・寸法から、既存軸へ**機械的に固定できる巻胴／アーム、抜け止め、荷重経路、巻込みを防ぐ囲い、倒れない支持、許容荷重**が確認できるまで、荷重試験は保留です。安全な取付部が無ければ、上の定性観察だけに留めます。測定のために本体を加工することを前提にしません。

後日その条件がそろった場合でも、硬貨は公称質量です。造幣局の[1円貨幣の記載](https://www.mint.go.jp/operations/production/operations_coin_presently-minted.html)は1g、直径20mm、純アルミニウムですが、使用済み各硬貨の質量下限を保証するものではありません。大量の貨幣の検査公差を1枚の許容差に読み替えません。

```text
名目負荷トルク [mN·m] = 0.00980665 × 名目質量 [g] × 有効半径 [mm]
```

たとえば1円硬貨の公称1gと半径30mmから得る**名目換算**は0.294mN·mです。これは取り付けてよい荷重でも、実証された下限でもありません。容器・治具・垂れる紐の重さ、紐の中心線までの半径、半径の変化、工具精度、質量の誤差を分けます。全質量や半径が不明なら数値下限は `null`、名目値または定性結果のままにします。

昨夜の計測仕様案にある22/50/102gは**未製作の新モジュールでの単位換算例**であり、手元のV2に掛ける荷重ではありません。現在のV2に対する許容試験質量は未設定です。

### 「持ち上がった」の範囲

承認できる治具・荷重・短い受皿間隔を確定した場合、初期角、観察する軸端、時計／反時計回り、巻上げ方向、実有効半径、持上げ高さをそろえて記録します。半径30mmで5mm持ち上げても回転角は約9.5°で、一周の確認にはなりません。スマートフォンのスローモーションは再生倍率・フレーム時刻を確認せずRPMへ変換しません。

無風時の戻り・初期摩擦・がた、初めから与えた回転や下がる重りの慣性を使っていないかも区別します。初期静止から実際に負荷を持ち上げた結果は**その軸・開始角・短い区間・支持条件の出力の証拠**で、未測定全角度や違う風車への保証ではありません。慣性で減速しながら進む区間を瞬時トルクの下限とはしません。

同じ入力軸受を通った後の出力から、その軸受損失を再び差し引きません。脚が接続されたままなら、その負荷も含む残余出力であり、風車単体の出力と呼びません。定量治具が成立しなくても、共通市販機基準での設計比較は継続できます。
