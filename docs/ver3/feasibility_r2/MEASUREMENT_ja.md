# 最小の入力確認案 — 全機を先に作らない

**`v3-r2-feasibility-02`／未製作・未実施の計測仕様案です。** 機器操作、購入、印刷を実行した手順書ではありません。新しい測定モジュールの製造CADもまだありません。ドライヤーの改造、吹出口・吸込口の閉塞、高温設定、固定方法の変更を前提にしません。冷風条件とメーカー取扱説明書を守るユーザー側の判断・操作が別途必要です。

目的は、三案の全機を印刷する前に、**実際の距離・吹付位置で得られる入力が、設計を続ける価値のある範囲か**を調べることです。型番だけを繰り返し尋ねたり、スマートフォンの動画だけから風速を作ったりしません。

## A. 風速計がある場合

型番、冷風設定、ノズル有無、出口から風車面までの距離、吹付方向、計器の測定範囲・精度を記録します。風車予定面の中央だけでなく、中央／上下／左右と外側の点を測り、**どの幅に有効な流れがあるか**を確認します。計器の検出部が大きい場合は細い噴流を平均してしまうため、その寸法も必要です。

カタログ風量はこの分布の代わりになりません。また、流速分布が得られても戻り側の負トルクや漏れは残るので、風速だけで全角度自己始動を合格にはできません。

## B. 風速計がなく、荷重の質量を確認できる場合

次の**共通の小型風車試験モジュール**を候補とします。まず中間径90mmで入口を確認し、必要なら同じ支持に120/60mmのローターだけを交換します。90mmの結果を面積や半径の単純倍率で他径の合格値へ換算しません。

| 計画要素 | 仕様の出発点 | 確認してから製造する点 |
|---|---|---|
| 風車 | 径90×幅48mm、今回の羽根パラメータ | 実CAD・印刷・保持・材料特性、実寸外径 |
| 軸 | 既製6mm D、140mm | 実軸の直径・平面5.5mm、印刷D穴のはめあい |
| 軸受 | 同一の686ZZを2個、支持中心20/120mm | 13mm外輪座、内輪専用スペーサ、シールド非接触 |
| 保持 | 軸方向カラー2個と外輪保持 | 締付で抵抗を増やさないこと。カラーはトルクキーではない |
| 荷重ドラム | 有効半径30mmを出発点とする単層溝 | 紐を含む**実有効半径**を測る。複数巻きで半径を増やさない |
| 支持台・保護囲い | 最大ローター径も受ける台、取付耳、囲い | 固定した台・回転体保持・荷重の小さい移動範囲を設計。未検証の台を手で支えない |
| 記録 | 開始角、荷重、半径、支持の状態、スマートフォン動画 | スマートフォンは動きの記録用で、校正された力計・風速計ではない |

必要な購入品をほぼ風車・軸・軸受に限定し、脚も歯車も不要にする案です。取付け・囲い・台の固定が完成していない状態で運転を勧めるものではありません。重量を大きくしたり高速回転させたりする破壊試験も目的にしません。

### 荷重で示せるトルク

質量と有効半径から既知の負荷を作れます。単位を揃えると次の関係です。

```text
負荷トルク [mN·m] = 0.00980665 × 質量 [g] × 有効半径 [mm]
```

| 半径30mmでの換算例 | 名目負荷トルク |
|---|---:|
| 22g | 6.47mN·m |
| 50g | 14.71mN·m |
| 102g | 30.01mN·m |

**これは使用する荷重・運転の指示や、合格する重さではありません。** 読み取り分解能と質量精度は別です。半径もCAD値ではなく、紐の厚さ・一層の巻き方・荷重中の位置を含めます。たとえば1g単位でしか分からない小さい荷重では数%の差が生じます。合否に使う場合は誤差を引いたトルク下限と比べます。

錘・紐に直接風が当たる、台が動く、ドラムが側面へ擦る、紐が重なる、手で予め回す、といった条件では比較できません。型番不明の計りの分解能だけを「精度±1g」と扱いません。

### 摩擦の校正と「正味」の区別

無風条件で両回転方向・複数の開始角の始動抵抗と偏りを記録し、支持・ローター偏心・紐の抵抗を切り分ける必要があります。静止した力計の表示を一回引くだけでは、静摩擦の履歴を除けません。重りによる追加のラジアル荷重も軸受抵抗を増やすので、都合よく無負荷値へ補正しません。

このモジュールで観測する、**同じ2個の入力軸受を通った後の正味トルク**は、計算側の「入力軸受2個を除いた下流要求」と比較します。軸受の抵抗を測定側でも計算側でも二重に差し引きません。

| 現版の高抵抗条件に対する設計側の目標 | A | B | C |
|---|---:|---:|---:|
| 正味トルクの余裕2倍目標 | 約29.96mN·m | 約6.39mN·m | 約14.23mN·m |

**2倍は設計側が選んだ余裕です。ユーザーの実測済み合格条件ではありません。** 実質量・摩擦・支持を確定したら再計算します。上の換算例は測定誤差分の余裕を含まないため、表の数値に近いという理由だけで合格にはできません。最新の正確な値は各 `candidate_*.json` の `measurement_target_static_net_input_nm` を参照します。

## C. 最小確認から全角度確認へ

最初の少数角での結果は、入力の桁が足りるかを見る**足切り**にだけ使います。成功した一角から全角度成功を推定しません。

必要な記録は、風車ID／版、開始角、実距離、ノズルと方向、荷重と半径の上下限、無風抵抗、変位方向、台の動き、停止・逆回転の有無です。全角度を主張する段階では一周の細かい標本と弱い角度の追加確認が必要です。標本間の狭い死点、機体側のクランク位相、接地切替はさらに別の確認です。

回転できる場合でも、回転中の供給トルク・仕事・30cmの継続性を静止試験だけで証明しません。必要入力を測れたあとで、同じ支持・ローター・版を使った機体設計へ進みます。
