## 試験片の組立順

1. **版と寸法を確認する。** まず2種類の試験片のみで、実ナット・座金・スリーブ・金属六角軸との適合を確認する。
   6mmスリーブの外径／穴／端面溝、M3ナットの対辺5.5mm・厚2.4mm想定、座金の穴径を測る。
   入らないものを押し込まず、穴・捕捉座の補正をCADへ戻す。ノズル径を精度保証にしない。
2. **歯車2個の側面から座金と内ナットを入れる。** [断面](gear-3.2.svg)の＋X側へ開いた溝を使い、
   内側座金→内ナットの順。ナットの平面を捕捉溝へ合わせる。まだ外側ナットを締めない。
3. **金属六角軸を入れ、歯車を軸方向に位置決めする。** 六角面で回り止めし、横から
   M3×20→座金→割締め部→内側座金→捕捉内ナット→外ナットの順にする。
   2.5mmキーで頭を保持し、5.5mmスパナで外ナットを内ナットへ当てる。
   根拠のない締付けトルクは指定しない。スリットの閉じ切り・白化・割れが出たら止める。
4. **同じ歯車を42mm軸間で噛み合わせる。** 試験対は42:42＝1:1で、Aの144:1減速機そのものではない。
   無負荷で歯先の引掛かりを確認するための対。軸支持治具・動力源は付属せず、動力運転しない。
   六角軸の位相は歯車に合わせ、印を付けて相対滑りと軸方向の動きを別々に見る。
5. **脚ピンは独立した作業台で組む。** ブラケットの側面から上座金→内ナットを入れる。
   6mmの耳間へ厚5.4mmリンクを置き、平滑スリーブを上下の穴とリンクへ通す。
   スリーブ端の溝は動く穴の中へ引っ掛けず、端面とバリを確認する。
6. **下からM3×20→下座金→12mmスリーブ→上座金→内ナット→外ナット。**
   締結力は金属スリーブ両端で受け、リンクを挟み込まない。[実断面](pivot-3.2.svg)と照合。
   名目軸方向すきま0.6mm、直径すきま0.2mm。ねじ先端の名目突出は2.2mm。
   実際の完全ねじ山のかかりを確認し、ナットの端だけで保持しない。
7. **自由回転と保持を別々に確認する。** 締結後にもリンクが軽く動くこと、スリーブが抜けないこと、
   ねじとナットが共回りしないことを確かめる。CADの±80°標本は実公差の全域保証ではない。
8. **結果を記録してから全機への設計を進める。** 組付け方向、実寸、引掛かり、白化、緩み、摩耗を記録。
   現在の試験部品を3.1のフレーム・脚へ穴拡大だけで取り付けない。
   入力6D部、全脚の層間隔、支持・ガード、床干渉、全機質量は次の統合設計対象。

## 計算で分かったこと／現物で確認すること

[検査JSON](checks.json)は同版native再読込、STEP対応、正の実体、全22点の配置、
側面挿入52標本、工具包絡4件、脚ピン±80°の17標本、1歯周期の噛合い19標本を記録します。
図は同じB-repの辺と切断形状です。表示クリップや分解図を、実際に組めた証拠としません。

歯車は既存のm1・42歯・圧力角25°・歯幅3.2mm・バックラッシュ0.3mmを使用。
接触比約1.362、最小歯先厚約0.539mm、歯元弦厚約2.251mm。
歯先0.539mmは「0.2mmノズルだから確実に強い」という意味ではありません。
荷重1N·mあたりの接線力は約47.62N、半径方向力は約22.21N。これは換算係数で運転荷重の指定ではありません。
PETGの許容歯荷重・疲労・摩耗はUNKNOWNで、歯元寸法だけから強度合格を出していません。

[比較JSON](comparison.json)では**歯車クランプ2か所＋自由ピン1か所だけ**を比較：
ねじの種類はM3×16／M2×16の2種類からM3×20の1種類へ、締結工具寸法は4種類から2種類へ。
ねじ3本・ナット6個は維持し、座金は2枚から6枚へ増やしました。
捕捉座・太い平滑スリーブ・厚いリンクは重量と外形が増える代償があります。
全3.2機の部品数・軽量化率・歩行抵抗・予算は未確定です。
旧Aの約1065g／部材約24,000円は9月の比較背景であり、新機の約束ではありません。

故障の切り分けは、(1)軸と歯車の空転、(2)軸方向の抜け、(3)樹脂クリープ、
(4)穴とスリーブの摩耗、(5)ねじの緩み、(6)歯の欠損です。
接着剤追加や強い増締めで一括して解決したことにしません。
ドライヤー冷風での自己始動・30cm歩行は未実施。旧3.1の120rpm表示も実測ではありません。

## 再現とルール

原コードは[CAD生成](../../../scripts/ver3/build_m3_trial.py)、
[0.2mm層検査](../../../scripts/ver3/slice_m3_trial.py)、
[一覧生成](../../../scripts/ver3/report_m3_trial.py)。既存FreeCAD 1.1.3／OrcaSlicer 2.4.2を使用。
必要なライブラリは既存要件を継承した `scripts/ver3/requirements_m3.txt`（断面経路用networkxを含む）。実行時はFreeCADのlibと既存Orcaの場所を引数で渡します。
生成器はネットワーク公開・購入・プリンター操作をしません。
FreeCAD APIは[公式API](https://freecad.github.io/SourceDoc/d8/ded/classPart_1_1TopoShape.html)と既存生成器に従います。
公式wikiの[Part API](https://wiki.freecad.org/Part_API)には古い情報を含む警告があるため、実環境で再読込・形状検査を行っています。

[Ver.3限定Instructions](../../../.github/instructions/ver3-assembly.instructions.md)に、M3・秋月／千石・0.2mm・V2完成版の保全を保存しました。
個人グローバル設定やuser memoryは変更していません。
