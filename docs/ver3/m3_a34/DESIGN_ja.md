# Ver.3.4 A — M3組立優先の統合開発版

公称版は2026-11-15の指定による**Ver.3.4**、内部IDは`v3.4-a-m3-r1`。
前段の[Ver.3.2接合試験](../m3_r1/README_ja.md)を保全して引き継ぐ。Ver.3.3の成果は作成していない。
完成版Ver.2、全体参照の3.1、3.2試験を上書きしない。

## 採用前の境界と調達例外

- Aの前・中央同期歯車だけに、試験済みの側面ナット座を実空間へ配置する。
  後ろの同期歯車は減速出力段に近いため旧部を保持。歯数・軸間隔は変更しない。
- 脚のA/DをM3＋外径6mmへ変更し、穴だけでなくボスと座金座を再設計する。
  固定PはM3外ナットとACリンクの静的干渉が生じたため、旧M2構造を保持する。
  小窓へ埋めたナットや、薄いリンクへ削り込む対処は採用しない。
  Bは13mmボスにしてもクランク40度でM6座金と右フレームが干渉するためM2を保持。
  フレームを薄く削る、精密な特殊小径座金へ戻す、脚層を広げる対処は採用しない。
  C/Eの三層接合、足の案内・ロッカー、同期アイドラーも4mm平滑部とM2を保持する。
  全箇所のM3化ではなく、限られた実空間・工具・既存足モジュールを保つ段階改訂。
- 市販M6座金（千石BSW6mm、M6×13×1.0）は厚さが旧M4座金と異なる。
  A/Dの実ボス端面へ0.3mmの座を作り、4.1mm層ピッチと元の足位置を変えずに逃がす。
  座金が樹脂を挟み込まないことを同じ実形状で検査する。
  ボス径15.4mmの候補はクランク30度で右フレームと干渉したため、13mmへ変更。
  端面を各0.3mm逃がした軸受幅は2.5mm。座金の径方向位置は金属スリーブで決まり、
  薄い捕捉リムで保持しない。旧リンク全体の拡縮やフレームを削る対処ではない。
- A根元は完成位置で干渉がなくても、元の首部がM3ねじ頭の挿入を妨げた。
  実クランクに直径6.2mmの軸方向通路を追加し、8mm座金は側面から座へ入れる。
  M3×30は通路から挿入する。六角軸受けと通路の外接円間には名目3.69mm以上を残す。
  脚・クランクを本体へ取り付ける前の独立ユニットとして組み、通常の2.5mmキーを使う。
- **20mmの連続金属スリーブのみ調達先の例外**とする。両店ではこの長さの
  M3金属中空品を確認できなかった。短い2本をつなぐと曲げ支持の不連続と
  部品数が増えるため、既存系統の国内メーカー廣杉計器CE-320Nを使う。
  公式表：長20mm、税抜26円、最小50個（2026-11-15確認）。
  https://hirosugi.co.jp/shop/g/gCE-301N/
  細かい切断・輸入専用軸・樹脂スリーブへの置換はしない。実在庫・送料は不明。
- 8mmスリーブ、M3ねじ・ナット・M3/M6座金は秋月／千石の公式掲載を参照する。
  20mmスリーブの最低購入lotと、試験体だけの900円を全機費用へ混同しない。
- 新反力とCAD質量による再計算を行う。元のドライヤー代理条件は未校正。
  実空力・摩擦、実始動、速度、30cm歩行の合格を宣言しない。
