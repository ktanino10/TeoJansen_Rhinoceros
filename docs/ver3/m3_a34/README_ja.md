## 接合部をどう固定するか

|接合|使用締結と回り止め|抜け止め・自由回転・工具|
|---|---|---|
|入力風車とハブ|既存M4×12四本、金属6Dハブを保持|入力カラーと軸受支持を保持。[3.1の入力部図](../m3_r1/input-3.1.svg)は変更していない部分の参照|
|前・中央の同期歯車|各M3×20一本、M3座金二枚、M3ナット二個。内ナットは側面の捕捉溝|六角面がトルクを伝え、割締めが軸方向を保持。2.5mmキー＋5.5mmスパナ。後ろの同期歯車は元形状|
|左右フレーム・軸受|既存の前六角キー／後逃げキーとM3/M4を保持|固定側／浮動側を区別。PETを圧縮スペーサーにせず、外輪押さえと内輪を混同しない|
|全6脚のA根元|各M3×30一本、M3座金二枚、M3ナット二個、連続20mm・外径6mm金属スリーブ|直径6.2mmの実通路からねじ頭とキーを通す。頭側座金は側面から。根元の樹脂座は締結力を受けるためクリープ確認が必要|
|全6脚のD関節|各M3×15一本、M3座金二枚、M3ナット二個、8mm・外径約6mm金属スリーブ|ねじ山でなく金属スリーブ上で回す。リンクを締めつぶさない。2.5mmキー＋5.5mmスパナ|
|P/B/C/E、足、アイドラー|M2・外径4mmの既存平滑部を保持|PはM3外ナットがACへ干渉。BはM6座金が動作中にフレームへ干渉。薄い特殊座金・削ったフレーム・広げた脚層へ逃げず、今回は変更しない|

**回り止め、軸方向保持、自由回転は別の機能です。接着剤だけでトルクを伝えません。**
確認されたV2の事象は風車・歯車と軸の相対滑りであり、焼付きとは断定していません。
空転、軸方向の抜け、樹脂クリープ、穴の摩耗、ねじ緩み、歯の破損を別々に調べます。
メーカー根拠のない締付けトルクは指定しません。白化・亀裂・閉じ切った割締め溝を増締めで隠さないでください。

## 番号付き組立計画

これは実作業済みの手順ではなく、**実CADに対応した組立計画**です。
HTMLの「全体／変更部／試験片」は構成の表示切替で、挿入アニメーションや作業順ではありません。

1. **版と仕分け。** 3.4印刷CSVとBOMを用い、保持した3.1部品と変更品を分ける。
   最初は[2種類の嵌合片](../m3_r1/print-list.csv)で実ナット・スリーブ・軸を確認。
   穴径6.2mmやナットの対辺5.5／高さ2.4mm想定を、0.2mmノズルだから正確とみなさない。
2. **前・中央歯車を作業台で準備。** 側面溝へ内側座金→内ナットを入れる。
   頭側からM3×20→座金→割締め部→内側座金→捕捉内ナット→外ナット。
   穴は元の金属六角軸に合わせて30度クロックした形状。旧3.2歯車をそのまま代用しない。
3. **左側から軸・減速系を配置。** 元の3.1手順01～03に沿って、固定側軸受、六角軸、複合歯車、同期歯車を準備。
   減速比は12×12＝144:1、同期歯車は42歯／42mm隣接ピッチ。軸間隔を変更しない。
4. **右フレームとPET。** 前キーと後逃げキーを合わせて閉じ、継手を締める。
   上PETのY方向−4mm退避、左右PETの保持は[元の具体手順04～05](../integrated_r7/ASSEMBLY_ja.md)を参照。
   金属座金で締結力を受け、PETで軸受を予圧しない。
5. **入力風車とガード。** 既存の金属6Dハブ、四点M4締結、前バスケット、後キャップを保持。
   X方向+4mmの一時退避と入力軸の順序は元の手順06～10を参照。
   旧経路・旧動画の合格を変更部の実組立成功へ転用しない。
6. **脚＋クランクを本体の外で準備。** A根元では8mm外径の頭側座金を側面から座へ入れ、
   M3×30を直径6.2mm通路から挿入。スリーブ、リンク、外側座金、内外ナットを合わせる。
   本体に取り付けてから狭い内側へ工具を押し込む順序にしない。
7. **Dと残りの脚を準備。** DはM3×15、8mmスリーブ、両端座金、二重ナット。
   A/D間のM6座金は0.3mm端面逃げへ置く。ボス径13mm、軸受幅2.5mmで、4.1mm層ピッチと元の足位置を保持。
   Pの固定締結は本体への取付け時に追加し、P/B/C/Eと足は元のM2仕様を使う。
8. **本体へ取付け・位相合わせ。** シャフト、クランクの正係合、固定Pの位置を合わせる。
   左右位相は前から0/180、180/0、0/180度。工具を使う単体工程を先に終える。
   ねじ・座金・ナットの向きを確認し、脚を挟み込まず、全周手回しの前にガードと保持を戻す。
9. **実物での確認を記録。** 固定部の相対滑りと抜け、自由部の引掛かり、実ねじ山のかかり、
   支持材除去、白化・亀裂、緩み・摩耗を分けて記録。指で無理に回したり、
   風量・加熱で不具合を押し切ったりしない。印刷・送風機運転はこの資料の公開だけでは実施しない。

[工具・ねじ挿入検査](access_check.json)は宣言した独立した歯車／脚クランク組立の範囲です。
キーは直径4mmの接近包絡、スパナは幅10mm・厚2mmの頭と31mm柄のゲージ。
実際の工具・手の空間、座金の側面投入、全機への連続挿入経路まで認定したものではありません。

## 印刷条件と入手先

STLは**mm・100%**。0.2mmはノズル径であり層高や精度保証ではありません。
新しい3.4歯車・ABリンク・クランクの[実層記録](slicing.json)を保存しています。
P1S／Generic PETG／層高0.10mmは検査用仮定で、実機種・実材料との一致は未確認。
支持を使う箇所・除去後の穴と座は現物確認が必要です。全115点のスライス・実造形合格ではありません。
機種仮定のあるG-code／3MFは配布せず、native／STEP／STLと実効設定の出典・hashを配布します。

新規締結候補は秋月のM3ナット114372、千石のM3×15/20/30六角穴付きねじ、
BSW3mm／BSW6mm座金、BSカラー3×8です。必要数、入数／最小注文、価格の単位と税込／税別、
公式URL、確認日は購入CSVで区別しています。手持ち数量はUNKNOWNで、購入はしていません。

**20mm連続金属スリーブCE-320Nだけは国内メーカーの調達例外**。
両店で取扱いを確認できず、短いスリーブ二本の接続は曲げ支持を途切れさせるため採りません。
[廣杉の公式表](https://hirosugi.co.jp/shop/g/gCE-301N/)で長20mm・税抜26円・最小50個を確認（2026-11-15）。
実在庫・送料は不明です。[例外と不採用理由](DESIGN_ja.md)を先に記録しています。
旧3.1の残存品は元の確認日・旧見積のままで、現在価格の確認済みとは扱いません。
旧正本の`source`とネストした`lots`双方からURL・販売単位・pack価格を保持しています。
同じ`purchase_group`の見積／切出し計画は一度だけ参照し、行数分を重複購入しません。
六角材の旧共通計画は500mm一本から100/100/100/58mm、PETは一枚から三つの切出しです。
**900円は3.2試験体の締結4品だけ。全機3.4の価格ではありません。**

## 改善と代償

M3ねじは**34→46本**、M2は50→38本、M4は14本を保持。
14か所の変更接合は2.5mmキー／5.5mmスパナに揃いましたが、全機の工具一式は減っていません。
ねじの径・長さの組合せは8→10種類。M3の手持ちを使いやすくする改訂であり、
部品総数や全工具数を減らしたという成果にはしません。

全機質量は体積と名目密度による計算で、約1.065kgから約1.12kgへ増加。
正確な値と、旧版を同じ解析器で再現した対照は[新旧比較](drive_comparison.json)にあります。
A/Dの径4→6mmは同じ荷重・摩擦係数なら摩擦トルク1.5倍ですが、
計算では新しい質量・重心・反力と、P/B/C/Eに残した4mmを別々に扱います。
低／名目／高抵抗、全周720姿勢と入力位相補間、各段の損失・反力を残します。

冷風6.4m/s・広がり20mmは未校正の代理条件。名目抵抗の余裕は小さく、
高抵抗・供給半減では不足します。負荷付き速度、自己始動、実30cm歩行はUNKNOWN。
旧120rpm表示を到達予測にしません。歯元寸法や実層の42歯を確認しても、
材料の許容歯荷重・積層疲労・摩耗を合格としません。
